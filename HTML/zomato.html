Backend Developer

Core Responsibilites

  • Microservices and API Development: Design and maintain robust, scalable APIs and backend services using languages like Go, Python, Java, or Node.js.
  • System Optimization: Reduce latency, handle massive daily request volumes, and improve the reliability of critical operations using caching systems like Redis or Memcache.
  • Cross-Functional Collaboration: Work closely with Android, iOS, and web frontend teams to define efficient API contracts, as well as with product managers and data scientists.
  • Production Troubleshooting: Autonomously investigate, debug, and resolve production issues, code blues, and system bottlenecks.
  • Architecture and Scale: Implement event-driven architectures via message queues like Kafka or RabbitMQ and manage containerized deployments using Docker and Kubernetes.

Skills Preferred

  • System Design and Architecture: Solid understanding of microservices architecture, RESTful/gRPC API design, and building high-throughput, low-latency distributed systems.
  • Databases and Caching: Experience with relational and non-relational databases (MySQL, PostgreSQL, MongoDB) and advanced caching layers (Redis, Memcached) to optimize query performance.
  • Event-Driven Systems: Familiarity with message brokers and streaming platforms like Apache Kafka or RabbitMQ for handling real-time asynchronous communication.
  • DevOps and Infrastructure: Practical knowledge of containerisation (Docker), orchestration tools (Kubernetes), and cloud platforms (AWS) to manage scalable deployments.
  • Data Structures and Algorithms: Strong problem-solving abilities and a deep understanding of core DSA concepts to write clean, optimized, and maintainable code.

Stipend:120000Rs+HRA+DA
