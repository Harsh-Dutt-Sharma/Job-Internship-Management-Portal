Software Engineer

Core Responsibilites

  • Feature Development: Design, write, and maintain clean, scalable, and secure code for Microsoft products, platforms, and cloud services using languages like C#, C++, TypeScript, or Python.
  • Cloud and Infrastructure Scale: Build and optimize high-availability microservices and distributed systems on Microsoft Azure, ensuring low latency, fault tolerance, and global scalability.
  • DevOps and Continuous Delivery: Own the full software development lifecycle (SDLC) by implementing continuous integration and deployment (CI/CD) pipelines, comprehensive automated testing, and proactive live-site monitoring.
  • Cross-Functional Collaboration: Work closely with Product Managers, Designers, Data Scientists, and fellow engineering teams to translate user requirements into technical architectures and product features.
  • Engineering Excellence: Participate actively in code reviews, mentor junior engineers, champion modern engineering practices, and contribute to standardizing technical documentation.
  • Data-Driven Iteration: Analyze telemetry, system logs, and user feedback data to debug complex production issues, eliminate performance bottlenecks, and iteratively improve user experience.

Skills Preferred

  • Core Languages: Proficiency in programming languages like C#, C++, Java, or Python, along with strong object-oriented programming (OOP) principles.
  • Data Structures and Algorithms: Deep understanding of core computer science fundamentals, DSA, and problem-solving to write efficient, optimized code.
  • Cloud Computing and Architecture: Experience building, deploying, and maintaining scalable distributed systems, microservices, and cloud infrastructure (ideally Microsoft Azure).
  • System Design: Ability to design high-throughput, low-latency architectures that support global, multi-tenant software systems.
  • DevOps and CI/CD: Familiarity with build pipelines, automated testing, continuous integration, continuous delivery, and live-site monitoring tools.
  • Database Management: Proficiency working with SQL/NoSQL databases, handling data modeling, and optimizing complex queries for distributed data storage.

Stipend:120000Rs+HRA+DA
