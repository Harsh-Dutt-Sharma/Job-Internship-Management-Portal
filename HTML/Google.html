Frontend Developer Intern

Core Responsibilites

  • Implementing Designs: Translate UX/UI wireframes and mockups into responsive, interactive web pages that work across multiple devices and browsers.
  • Collaboration: Work closely with UX designers, product managers, and back-end engineers to integrate APIs and deliver functional solutions.
  • Optimization and Testing:Debug code, troubleshoot interface issues, and optimize web applications for maximum speed, scalability, and accessibility.
  • Team Participation:Take part in code reviews, write technical documentation, and learn industry best practices under the guidance of experienced engineers

Skills Preferred

  • Core Web Technologies:Mastery of HTML5, CSS3 (including responsive design, Flexbox, and Grid), and Modern JavaScript (ES6+ features, asynchronous programming, and DOM manipulation).
  • Frameworks & Libraries:Proficiency in at least one major frontend framework, with Angular being highly preferred at Google, though strong skills in React or Vue are widely accepted.
  • Computer Science Fundamentals: Solid understanding of Data Structures and Algorithms (arrays, trees, graphs, sorting, and recursion) for the technical interview process.
  • Testing & Tools:Experience with version control via Git and frontend testing frameworks like Jest, Karma, or Cypress.

Stipend:50000Rs+HRA+DA
